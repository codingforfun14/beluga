# BELUGA

Materiale di riferimento per le motion graphics del progetto BELUGA.

- `reference-pack/`: font (OFL), icone (Lucide, Iconify), libreria di motion graphics e categorie di animazioni con sorgenti HTML, script di render e clip MP4. Vedi `reference-pack/LEGGIMI.md`.
- `stock-finanza/`: elenco dei video stock commerciali (CSV con fonte e licenza) e log del download. I video veri (circa 1,1 GB) restano fuori dal repository: sono sul Mac in `Desktop/DIGITALIZA/BELUGA-reference/stock-finanza/` e si possono riscaricare dagli URL nel CSV.
