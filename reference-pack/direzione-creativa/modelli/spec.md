# Spec di direzione artistica

Ogni aggettivo del brief diventa un numero.

| Voce | Valore |
|---|---|
| Categorie di stile (max 3) | |
| Formato e durata | es. 9:16, 15 s, 30 fps |
| Palette | max 3 colori + neutro, in esadecimale |
| Font | titolo, testo, dimensione minima 28 px |
| Ritmo | durata media inquadratura in secondi, tagli sul beat (BPM) |
| Ease | arrivi, uscite, camera |
| Motion blur | sì / no, pixel di picco |
| Texture | grana, vignetta, opacità |
| Suono | musica (BPM, mood), effetti su quali azioni, voce |
| Asset | cosa è codice, cosa è immagine Kling, cosa è video Kling |
| Primo fotogramma | cosa si vede a t = 0 |
| Vietato | scelte banali escluse, per nome |
| Reference | 3-5 link, ognuno con cosa prendiamo |
